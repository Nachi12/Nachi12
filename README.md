**AI Agent Orchestration Platform**

An LLM call isn't infrastructure. AgentDesk explores the layer underneath autonomous agents — isolated execution, observability, state, and cleanup — running each agent inside its own disposable Docker container with a live `Think → Act → Observe` trace streamed over Socket.io.

- Docker container per agent execution, auto-cleaned on timeout
- PostgreSQL + Prisma for structured state, MongoDB for raw LLM traces

## `~/how-i-build`

```

Idea → User Problem → System Design → Database → API → Frontend
→ Test → Docker → CI/CD → Deploy → Observe

```

| Principle | What it means |
|---|---|
| **Product thinking** | Start with the workflow, not the ticket. |
| **Data integrity** | Validation, idempotency, and isolation are first-class. |
| **System design** | Frontend, API, DB, auth, and infra work as one system. |
| **Observability** | If it breaks in prod, I want to know what, where, and why. |
| **Ship** | Working locally isn't done. Used by real users is done. |
