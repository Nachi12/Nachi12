### 💰 ProductivityOS — Personal Finance Management SaaS
> Full-featured finance platform with bank statement analysis and family-level data isolation

- 🏦 Bank statement upload pipeline — parsing, normalisation, categorisation, duplicate detection, and batch import
- 📈 Financial analytics — income vs expenses, net cash flow, savings rate, category breakdown, monthly comparisons
- 💱 Deterministic financial calculations using integer paise-based monetary representation
- 🔒 Firebase Authentication + layered Express API with Zod validation, rate limiting, and MongoDB indexing
- ✅ Idempotent statement processing — prevents duplicate transactions on repeated imports
- 🧪 Unit tested with Vitest/Jest and CI/CD via GitHub Actions

**Stack:** `React.js` `TypeScript` `Node.js` `Express.js` `MongoDB` `TanStack Query` `Firebase Auth` `Zod` `Vitest` `GitHub Actions`
